# flutter_course_inno

Это официальный репозиторий курса "Принципы управления разработкой программных продуктов".


В него будут загружать примеры кода с лекций и ответы на практические задания.

Для того, чтобы запустить код конкретной лекции в терминале выполните команду
```
flutter run <пусть к файлу>
```

Для того, чтобы запустить файл с лекции:
```
flutter run lib/lecture1/main.dart
```
